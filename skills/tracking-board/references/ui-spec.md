# สเปกหน้าจอบอร์ดติดตามงาน (ใช้ได้ทุกเฟรมเวิร์ก)

สร้างหน้าตาม spec นี้ด้วย component / UI kit / design token ของโปรเจกต์ปลายทาง
ตัวอย่างที่ทำงานจริง (Vue 3) อยู่ใน `references/vue/` — อ่านเทียบได้ แต่**อย่าก๊อปตรงๆ** เพราะผูกกับ UI kit ของโปรเจกต์ต้นทาง

ข้อมูล / API / ป้ายสถานะ ทั้งหมดเรียกจากโค้ดแกน (`tracking-api.ts` · `tracking-labels.ts`) — หน้าจอห้ามเขียนคำ/สีสถานะเอง

> spec นี้เขียนด้วย**ค่าเริ่มต้น** (สถานะมาตรฐาน 5 · ภาษาไทย · ช่องเสริมครบ · ชื่อตอนคอมเมนต์+สร้าง/แก้)
> ผู้ใช้เลือกต่างตอนสัมภาษณ์ → ปรับตาม `customize.md` แล้วอ่าน spec โดยแทนคำ/สถานะให้ตรง

## สารบัญ
1. โครงหน้า · 2. การ์ดตัวเลข · 3. ตัวกรอง · 4. มุมมอง 3 แบบ · 5. การ์ดเรื่อง · 6. กล่องรายละเอียด ·
7. ฟอร์มสร้าง/แก้ · 8. การบันทึก · 9. สถานะโหลด · 10. มือถือ/a11y · 11. เช็คลิสต์

## 1. โครงหน้า

- route สาธารณะ (เช่น `/tracking`) **ไม่ต้องล็อกอิน · ไม่ใช้ layout หลังล็อกอินของแอป** · ใช้ได้ทุกโหมด build
- หัวหน้า: โลโก้ · ชื่อ "ติดตามงาน <ชื่อโปรเจกต์>" · บรรทัดรอง "คำถามที่รอคำตอบ · requirement ที่ค้าง · ของที่ขอเพิ่ม · ข้อมูล ณ <เวลาโหลด>" ·
  ปุ่ม **+ เพิ่มเรื่อง** · **ดาวน์โหลด CSV** (ตามตัวกรอง · ปิดเมื่อไม่มีเรื่อง) · **รีเฟรช** (โหลดอยู่ = loading)
- ความกว้าง: มุมมองบอร์ดกว้าง ~1600px (ให้เห็นครบ 5 คอลัมน์) · มุมมองอื่น ~1150px
- ลำดับในตัวหน้า: แถบเตือน → การ์ดตัวเลข → การ์ดตัวกรอง → แถว "N เรื่อง (กรองอยู่)" + ปุ่มสลับมุมมอง → เนื้อหา
- แถบเตือน: `source === 'mock'` → แถบฟ้า "ข้อมูลตัวอย่าง — ยังไม่ได้ต่อ Google Sheets · สร้าง/แก้/คอมเมนต์อยู่แค่ในหน้านี้" ·
  `warning` (โหลดสดไม่ได้ ใช้ชุดที่จำไว้) → แถบส้ม

## 2. การ์ดตัวเลข (4 ใบ · มือถือ 2×2)

| ใบ | ค่า | บรรทัดล่าง | กดได้ |
| --- | --- | --- | --- |
| รอตอบ | นับ `waiting_client` | "ค้างเกิน 7 วัน N เรื่อง" (แดง) / "ไม่มีเรื่องค้างนาน" | ✅ |
| รอทีมเรา | นับ `waiting_team` | — | ✅ |
| กำลังทำ | นับ `in_progress` | — | ✅ |
| ความคืบหน้า | `round(done ÷ (ทั้งหมด − พักไว้) × 100)%` | "เสร็จ X จาก Y เรื่อง (ไม่นับพักไว้)" | ❌ |

- กด 3 ใบแรก = กรองสถานะนั้น · กดซ้ำ = ยกเลิก (กลับเป็นทั้งหมด) · ใบที่เลือกมีกรอบสี primary · `aria-pressed`
- ใบไหนกดได้ให้เป็นปุ่มจริง (`<button>`) ไม่ใช่ div คลิกได้

## 3. ตัวกรอง (ใช้ร่วมทุกมุมมอง · ค่าเริ่มต้น "ไม่เลือกอะไร")

- **แท็บสถานะ**: ทั้งหมด (ค่าเริ่มต้น) · ยังค้าง (= ไม่ใช่เสร็จแล้ว/พักไว้ · ใช้ `isTrackingOpen`) · แต่ละสถานะที่มีเรื่อง (ตัวที่เลือกอยู่ห้ามหายแม้นับได้ 0) · โชว์จำนวนในแท็บ
  - ค่าเดียวกับการ์ดตัวเลข — กดการ์ดแล้วแท็บต้องเลื่อนตาม
- ค้นคำ (รหัส · หัวข้อ · รายละเอียด · คำตอบ ไม่สนตัวพิมพ์เล็กใหญ่) · ประเภท · โมดูล (ค้นได้) · รอบส่งงาน
  - **ทุกช่องต้องมีปุ่มกากบาทล้างค่า** (ผู้ใช้ท้วงมาแล้วรอบหนึ่ง) · ตัวเลือกโมดูล/รอบส่งงานสร้างจากค่าที่มีจริงในข้อมูล (ไม่ตั้งรายการตายตัว)
- ปุ่ม **"ล้างตัวกรองทั้งหมด"** มุมขวาของการ์ดตัวกรอง → กลับค่าเริ่มต้นทุกช่อง · กดไม่ได้ตอนไม่มีตัวกรอง · มุมมองที่ดูอยู่ไม่เปลี่ยน
- แถบอธิบายสถานะใต้ตัวกรอง (`TRACKING_STATUS_LEGEND`: ป้าย + คำอธิบาย 1 บรรทัด)

## 4. มุมมอง 3 แบบ (ปุ่มสลับแบบ segmented)

### บอร์ด (ค่าเริ่มต้น — แบบ Trello)
- คอลัมน์ = `TRACKING_BOARD_STATUSES` (รอตอบ · รอทีมเรา · กำลังทำ · เสร็จแล้ว · พักไว้) + คอลัมน์ "ไม่ทราบสถานะ" **เฉพาะตอนมีค่าพิมพ์ผิดในชีต** (ลากเข้าไม่ได้ · ไม่มีปุ่ม +)
- ตัวกรองสถานะเลือกอยู่ → โชว์เฉพาะคอลัมน์นั้น ("ยังค้าง" = ซ่อนเสร็จแล้ว/พักไว้)
- หัวคอลัมน์: ป้ายสถานะ · จำนวน · ปุ่ม + (สร้างเรื่องโดยตั้งสถานะเป็นคอลัมน์นั้น) · ท้ายคอลัมน์มีปุ่ม "+ เพิ่มเรื่อง" อีกจุด
- คอลัมน์ว่าง → กรอบเส้นประ "ลากการ์ดมาวางที่นี่"
- **ลากการ์ดข้ามคอลัมน์ = เปลี่ยนสถานะ** — ใช้ HTML5 drag & drop ได้ (ไม่ต้องเพิ่ม lib) · ไฮไลต์คอลัมน์ที่ลากผ่าน · การ์ดที่กำลังลากจาง ·
  `dataTransfer.setData('text/plain', id)` (Firefox ไม่ยอมลากถ้าไม่ setData) · การ์ดต้องเป็น `div[role=button]` ไม่ใช่ `<button>` (Firefox ไม่เริ่มลากจากปุ่ม)
- บอร์ดเลื่อนแนวนอนในกล่องของตัวเอง — **ตัวหน้าห้ามเลื่อนข้าง** · คอลัมน์กว้าง ~256px
- มือถือลากไม่ได้ (HTML5 DnD ไม่รองรับ touch) → เปลี่ยนสถานะจากกล่องรายละเอียดแทน

### รายการ
- การ์ดเรียงลงมา (โหมดเต็ม) · ว่าง → "ไม่มีเรื่องที่ตรงกับตัวกรอง" / "ยังไม่มีเรื่อง — กด เพิ่มเรื่อง เพื่อเริ่ม"

### ตามรอบส่งงาน
- กลุ่มตาม `release` (เรียงแบบ numeric · "ยังไม่จัดรอบ" ไว้ท้าย) · หัวกลุ่ม "รอบส่งงาน v0.3 · เสร็จ X/Y · รอตอบ N" + แถบความคืบหน้า
- ⚠️ ตัวเลข X/Y และแถบนับจาก**ทุกเรื่องในรอบ** ไม่ขึ้นกับตัวกรอง (เคยพลาด: กรอง "ยังค้าง" แล้วทุกรอบขึ้น 0/N) · ไม่นับพักไว้

**การเรียงทุกมุมมอง**: `TRACKING_STATUS_ORDER` → ความสำคัญ (สูง→ไม่ระบุ) → กำหนดเสร็จใกล้สุดก่อน (ไม่กำหนดไว้ท้าย) → ถามมานานก่อน

## 5. การ์ดเรื่อง (ใช้ทั้งบอร์ดและรายการ)

- บรรทัด 1: รหัส (mono) · ป้ายสถานะ (ซ่อนในโหมดบอร์ด — คอลัมน์บอกแล้ว) · ประเภท · โมดูล · ความสำคัญ (ถ้ามี) · ขวาสุด "ค้าง N วัน"
  - "ค้าง N วัน" เฉพาะ `waiting_client`/`waiting_team` (`trackingOpenDays`) · เกิน 7 วัน = แดง · (กำลังทำ/เสร็จ ไม่ขึ้น — เคยพลาดให้กำลังทำขึ้นแดง)
- หัวข้อ (ตัวหนา) · "🚫 ติดอยู่: <blocks>" สีส้ม · "คำตอบ: …" 2 บรรทัด (โหมดรายการเท่านั้น)
- บรรทัดล่าง: 📅 "กำหนด 15 ต.ค." + label จาก `trackingDueState` (เลยกำหนด = แดง · วันนี้/≤2 วัน = ส้ม · เสร็จ/พักไว้ไม่เตือน) · "รอบส่งงาน v0.3" · 💬 จำนวนคอมเมนต์
- กดทั้งการ์ด / Enter / Space = เปิดกล่องรายละเอียด

## 6. กล่องรายละเอียด (modal)

- เปิดจาก URL `?item=<รหัส>` ได้ (ส่งลิงก์รายเรื่องในแชต) — เปิดเรื่อง = `router.replace` เติม query · ปิด = เอา query ออก (replace ไม่ให้ history รก) ·
  รอข้อมูลโหลดเสร็จก่อนค่อยเปิด (ลิงก์ที่วางตรงๆ ต้องเปิดได้)
- **คลิกนอกกล่อง / กด Esc ไม่ปิด** (ผู้ใช้สั่ง — กันพิมพ์ค้างหาย) → ต้องมีปุ่ม "ปิด" ที่ footer
- หัว: "T-003 · หัวข้อ" · แถบจัดการ: ตัวเลือก **สถานะ** (เปลี่ยน = ย้ายสถานะ · ทางเดียวบนมือถือ) · ปุ่ม **แก้ไข** · ปุ่ม **ซ่อนจากบอร์ด** (ยืนยันก่อน: "หายจากบอร์ดของทุกคน แต่แถวในชีตยังอยู่")
- ข้อมูล: ป้ายประเภท/โมดูล/ความสำคัญ · วันที่ถาม · วันที่ตอบ · กำหนดเสร็จ (+ป้ายเลยกำหนด) · รอบส่งงาน · สร้างโดย/แก้ล่าสุด (ถ้ามี) ·
  รายละเอียด · กล่องส้ม "งานที่ติดเพราะเรื่องนี้" · กล่องเขียว "คำตอบ / ข้อสรุป" · ลิงก์ (target=_blank rel=noopener)
- คอมเมนต์ เก่า→ใหม่ (ชื่อ · เวลา · ข้อความ) · ผู้เขียนว่างให้โชว์ "ไม่ระบุชื่อ"
- ฟอร์มคอมเมนต์: **ช่อง "ชื่อผู้คอมเมนต์" ต้องกรอก · เริ่มว่างทุกครั้งที่เปิดกล่อง · ไม่จำ ไม่เติมให้** (ผู้ใช้: เติมให้แล้วคนจะมักง่ายไม่แก้ชื่อตัวเอง) ·
  ข้อความ (นับตัวอักษร ≤ 2000) · ส่งแล้วล้างทั้งชื่อและข้อความ · เติมคอมเมนต์เข้าลิสต์เลยไม่ต้องโหลดใหม่
- ข้อความทุกช่องแสดงแบบตัวหนังสือล้วน (escape) **ห้าม render HTML** — ใครก็พิมพ์ลงชีตได้

## 7. ฟอร์มสร้าง/แก้ (modal เดียวกัน · คลิกนอก/Esc ไม่ปิด · ปุ่ม ยกเลิก / สร้างเรื่อง|บันทึก)

ช่อง: หัวข้อ* · ประเภท · สถานะ · ความสำคัญ · **กำหนดเสร็จ (Deadline)** · โมดูล · รอบส่งงาน · วันที่ถาม (สร้างใหม่ตั้งเป็นวันนี้) · วันที่ตอบ ·
รายละเอียด · งานที่ติดเพราะเรื่องนี้ · คำตอบ/ข้อสรุป · ลิงก์ (`https://`) · **ชื่อผู้บันทึก*** (เริ่มว่างทุกครั้ง · ไม่จำ)

- ตรวจด้วย `validateTrackingItem` + `validateTrackingAuthor` → แสดงข้อผิดพลาดใต้ช่อง
- สร้างจากปุ่ม + ของคอลัมน์ → สถานะเริ่มต้น = คอลัมน์นั้น
- แก้ไข: ส่งเฉพาะช่องที่เปลี่ยน · ไม่มีอะไรเปลี่ยน = ปิดเฉยๆ
- วันที่ในฟอร์มเป็น `yyyy-mm-dd` (เวลาเครื่อง) — แปลงไป/กลับกับ ISO ของข้อมูล
- สร้างเสร็จ → เปิดกล่องรายละเอียดของเรื่องใหม่ให้ (ส่งลิงก์ต่อได้ทันที) · toast "สร้างเรื่อง T-00X แล้ว"

## 8. การบันทึก

| การกระทำ | เรียก | ชื่อ |
| --- | --- | --- |
| คอมเมนต์ | `postTrackingComment({ itemId, author, message })` | ต้องมี |
| สร้าง | `createTrackingItem(input, author)` | ต้องมี |
| แก้จากฟอร์ม | `updateTrackingItem(item, changes, author)` | ต้องมี |
| ลากย้ายสถานะ / ตัวเลือกสถานะในกล่อง | `updateTrackingItem(item, { status })` | **ไม่ถาม** |
| ซ่อน | `archiveTrackingItem(item)` | ไม่ถาม |

- ลากย้าย: **ย้ายการ์ดบนจอทันที (optimistic)** → บันทึก → พลาดย้ายกลับที่เดิม + toast แดงค้าง · กันลากซ้ำระหว่างบันทึก · ผลลัพธ์มี `log` (คอมเมนต์ "ย้ายสถานะ") ให้เติมเข้าลิสต์
- error "มีคนแก้เรื่องนี้ไปก่อนแล้ว — กดรีเฟรช" มาจากการกันแก้ทับ (`updatedAt`) → แสดงตามข้อความ
- ทุก error เป็นข้อความไทยพร้อมโชว์แล้ว (toast แดง ค้างจนกดปิด)

## 9. สถานะโหลด

- โหลดครั้งแรก: การ์ดตัวเลขเป็น skeleton + การ์ดเรื่อง skeleton 4 แถว
- รีเฟรช: เก็บข้อมูลเดิมไว้บนจอระหว่างโหลด (ไม่กะพริบว่าง)
- โหลดไม่ได้และไม่มีชุดที่จำไว้: การ์ด "โหลดข้อมูลไม่สำเร็จ" + ข้อความ error + ปุ่มลองใหม่
- `source === 'cache'`: แถบส้ม "กำลังแสดงข้อมูลชุดล่าสุดที่เคยโหลดไว้" + เหตุผล

## 10. มือถือ / a11y

- กว้าง 390px ต้องไม่มีเลื่อนข้างที่ตัวหน้า (บอร์ดเลื่อนในกล่องได้) · การ์ดตัวเลข 2×2 · ตัวกรองซ้อนลงมา
- ป้าย/ปุ่มไอคอนมี `aria-label` · คอลัมน์บอร์ดเป็น `section` มี `aria-label="คอลัมน์ <สถานะ>"` · ปุ่มสลับมุมมอง/การ์ดตัวเลขใช้ `aria-pressed`

## 11. เช็คลิสต์ก่อนส่ง

- [ ] เปิด `/tracking` โดยไม่ตั้ง URL → เห็นแถบข้อมูลตัวอย่าง + 6 เรื่องตัวอย่าง
- [ ] กดการ์ดตัวเลข → บอร์ดเหลือคอลัมน์เดียว · กดซ้ำกลับครบ · ล้างตัวกรองทั้งหมดได้
- [ ] สร้างเรื่องไม่ใส่ชื่อ → เตือน · ใส่ชื่อ → ได้ T-00X + เปิดกล่องให้
- [ ] ลากการ์ด → ย้ายคอลัมน์ ไม่มีกล่องถามชื่อ · มีคอมเมนต์ "ย้ายสถานะ"
- [ ] คอมเมนต์ไม่ใส่ชื่อ → เตือน · ส่งแล้วชื่อถูกล้าง
- [ ] คลิกนอกกล่อง / Esc → กล่องไม่ปิด · ปุ่มปิดใช้ได้
- [ ] `?item=T-001` เปิดกล่องเรื่องนั้นเอง
- [ ] จอ 390px ตัวหน้าไม่เลื่อนข้าง
- [ ] build จริงไม่ตั้ง URL → "ยังไม่ได้ตั้งค่า" ไม่โชว์ข้อมูลตัวอย่าง · ไฟล์ข้อมูลตัวอย่างไม่ถูกโหลด
