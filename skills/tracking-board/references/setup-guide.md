# คู่มือตั้งค่า Google Sheets ให้บอร์ดติดตามงาน (`/tracking`)

> ไฟล์นี้เขียนให้**ผู้ใช้**ทำเอง (Claude เข้าบัญชี Google ของผู้ใช้ไม่ได้) — ก๊อปไปไว้ในโปรเจกต์คู่กับ `Code.gs`
> แล้วแก้ชื่อ env / โดเมนให้ตรงโปรเจกต์ก่อนส่งให้ผู้ใช้

บอร์ดแบบ Trello (สร้างเรื่อง · แก้ · ลากย้ายสถานะ · ซ่อน · คอมเมนต์) ข้อมูลเก็บใน Google Sheet
ผ่าน **Google Apps Script Web App** ไม่ผ่าน backend ของโปรเจกต์

- **ไม่มีล็อกอิน** — คอมเมนต์ · สร้าง · แก้ไข ต้องพิมพ์ชื่อเองทุกครั้ง (ไม่เติมให้) · ลากย้ายสถานะ · ซ่อน ไม่ระบุชื่อ

## 1. สร้างชีต + วางสคริปต์

1. สร้าง Google Sheet ใหม่ (ตั้งชื่อเช่น `Project Tracking`)
2. เมนู **Extensions → Apps Script** → ลบโค้ดเดิม → วางเนื้อหา `Code.gs` ทั้งไฟล์ → กด Save
3. ⚙️ **Project Settings → Time zone** = เขตเวลาของทีม (ไทย: GMT+07:00 Bangkok) — วันที่จะได้ไม่เพี้ยนไป 1 วัน
4. เลือกฟังก์ชัน **`setupSheets`** → กด **Run** → อนุญาตสิทธิ์
   → ได้แท็บ `items` กับ `comments` พร้อมหัวคอลัมน์ · checkbox · dropdown (ชีตเริ่มว่าง สร้างเรื่องจากหน้าเว็บได้เลย)

## 2. Deploy เป็น Web App

1. **Deploy → New deployment** → ประเภท **Web app**
   - **Execute as:** Me
   - **Who has access:** **Anyone** ← ต้องเป็นค่านี้
     (หน้าเว็บอยู่คนละโดเมนกับ Google — ตั้ง "Anyone within <โดเมนบริษัท>" แล้วเบราว์เซอร์จะติด CORS
     เพราะไม่ส่งคุกกี้ล็อกอิน Google ข้ามโดเมน ต่อให้ผู้ใช้ล็อกอินบัญชีบริษัทค้างไว้ก็ตาม)
2. Deploy → คัดลอก **Web app URL** (ลงท้าย `/exec`)
3. ใส่ URL ใน env ฝั่ง client ของโปรเจกต์ (ชื่อตัวแปรตาม `tracking-config.ts`) แล้ว build/รันใหม่ — ค่าฝังตอน build

> แก้ `Code.gs` ทีหลัง → Save → Run `setupSheets` (เผื่อมีคอลัมน์ใหม่) →
> **Deploy → Manage deployments → ✏️ แก้ deployment เดิม → Version: New version** (URL เดิม ไม่ต้องแก้ env)
> ถ้ากด New deployment จะได้ URL ใหม่ ต้องเปลี่ยน env ตาม

## 3. ใช้งาน

**บนหน้าเว็บ**

- **+ เพิ่มเรื่อง** → กรอก "ชื่อผู้บันทึก" ด้วย → รหัส `T-###` ออกให้อัตโนมัติ · เผยแพร่ทันที
- **ลากการ์ด**ข้ามคอลัมน์ = เปลี่ยนสถานะ (มือถือ: เปลี่ยนจากตัวเลือก "สถานะ" ในกล่องรายละเอียด)
  → ระบบเขียน "ย้ายสถานะ: ก → ข" ลงคอมเมนต์ให้
- กดการ์ด → **แก้ไข** ทุกช่อง (รวมกำหนดเสร็จ) · **ซ่อนจากบอร์ด** (แถวในชีตยังอยู่) · **คอมเมนต์**
- ถ้ามีคนแก้เรื่องเดียวกันไปก่อน ระบบจะบอกให้รีเฟรช (ไม่ทับกันเงียบๆ)

**ในชีต** (ทีมแก้ตรงได้)

| คอลัมน์ | กรอกอะไร |
| --- | --- |
| `id` | รหัสเรื่อง ห้ามซ้ำ เช่น `T-015` (สร้างจากหน้าเว็บได้รหัสต่อจากเลขสูงสุดให้เอง — นับรวมแถวที่ซ่อน) |
| `publish` | ✅ ติ๊ก = ขึ้นบอร์ด · ไม่ติ๊ก = ไม่ส่งออกไปเลย (เก็บเรื่องภายในในชีตเดียวกันได้ · ปุ่ม "ซ่อน" ก็คือเอาติ๊กออก) |
| `type` | คำถาม · requirement · ขอเพิ่ม · แจ้งปัญหา · ข้อตกลง |
| `module` | ข้อความอิสระ — ตัวกรองในหน้าเว็บสร้างจากค่าที่มีจริง |
| `title` / `detail` | หัวข้อ / รายละเอียด |
| `status` | รอตอบ · รอทีมเรา · กำลังทำ · เสร็จแล้ว · พักไว้ (= คอลัมน์บนบอร์ด) |
| `priority` | สูง · กลาง · ต่ำ (ว่างได้) |
| `askedAt` / `answeredAt` | วันที่ถาม / วันที่ได้คำตอบ — ใช้นับ "ค้าง N วัน" |
| `dueAt` | กำหนดเสร็จ — เลยกำหนดแล้วยังไม่เสร็จ การ์ดขึ้นแดง |
| `answer` | คำตอบหรือข้อสรุป |
| `release` | รอบส่งงาน เช่น `v0.3` |
| `blocks` | งานที่ติดเพราะเรื่องนี้ (โชว์สีส้มบนการ์ด) |
| `link` | ลิงก์เอกสาร/ภาพ (รับเฉพาะ `http(s)://`) |
| `createdBy` · `updatedBy` | ชื่อที่พิมพ์ในฟอร์มสร้าง/แก้ · ลากแล้ว `updatedBy` ว่าง |
| `createdAt` · `updatedAt` | ระบบกรอกให้ — **ห้ามแก้ `updatedAt` เอง** (ใช้กันแก้ทับกัน) |

แท็บ `comments`: ลบแถวคอมเมนต์ที่ไม่ต้องการได้เลย

## 4. เอาขึ้นเว็บจริง — ต้องมี SPA fallback

หน้าเว็บส่วนใหญ่เป็น SPA (router โหมด history) → กดเมนูในแอปเข้า `/tracking` ได้ แต่**วาง URL ตรงๆ / กดรีเฟรช แล้ว 404**
เพราะเซิร์ฟเวอร์ไม่มีไฟล์ชื่อ `/tracking` — ต้องตั้งให้ "หาไฟล์ไม่เจอ ส่ง `index.html`"

| โฮสต์ | ตั้งค่า |
| --- | --- |
| Cloudflare Workers (static assets) | `wrangler.jsonc` → `"assets": { "directory": "./dist", "not_found_handling": "single-page-application" }` |
| Cloudflare Pages | ไม่ต้องทำอะไร **ถ้าไม่มีไฟล์ `404.html` ที่ราก output** (มีเมื่อไรจะปิด SPA mode) |
| Netlify | `public/_redirects` → `/*  /index.html  200` |
| Vercel | `vercel.json` → `{ "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }] }` |
| Nginx | `location / { try_files $uri $uri/ /index.html; }` |
| Next.js / Nuxt (มี server) | ไม่ต้อง — route จริงอยู่แล้ว |

## หมายเหตุ

- ใครมีลิงก์หน้าเว็บก็ใช้บอร์ดได้ · ชื่อพิมพ์เอง จึงปลอมได้ — อย่าใส่ข้อมูลลับในเรื่องที่เผยแพร่
- สคริปต์ตรวจซ้ำทุกการเขียน: ชื่อต้องมีตอนคอมเมนต์/สร้าง (≤ 60 ตัวอักษร) · ความยาว · ค่าตัวเลือก · ลิงก์ต้องเป็น http(s) ·
  ข้อความขึ้นต้น `= + - @` เก็บเป็นตัวหนังสือ (ไม่กลายเป็นสูตร) · เขียนรวมไม่เกิน 60 ครั้ง/นาที
- เรื่องที่ซ่อนไว้ (ไม่ติ๊ก publish) ไม่ถูกส่งออกไปหน้าเว็บ รวมถึงคอมเมนต์ของเรื่องนั้น
