# tracking-board

สกิลสำหรับ [Claude Code](https://claude.com/claude-code) ที่สร้าง**บอร์ดติดตามงานแบบ Trello** ลงในโปรเจกต์เว็บของคุณ ใช้ร่วมกับลูกค้า/หัวหน้าตอนประชุมหรือส่งงาน:
- **รวมเรื่องที่ค้าง:** คำถามที่รอคำตอบ · requirement ค้าง · ของที่ขอเพิ่ม · bug
- **เก็บข้อมูลใน Google Sheets** ผ่าน Apps Script — ไม่ต้องมี backend แก้ในชีตตรงๆ ก็ได้
- **ใช้ได้ทุกเฟรมเวิร์ก:** Vue · React · Next.js · Nuxt · Svelte (มีตัวอย่าง Vue 3 ที่ใช้งานจริง)
- **ถามก่อนสร้าง:** สกิลสำรวจโปรเจกต์แล้วสัมภาษณ์สั้นๆ (ชื่อบอร์ด · path · ชุดสถานะ · ภาษา · ช่องที่ต้องการ · กติกาเก็บชื่อ) ให้บอร์ดตรงงานของคุณ

## ติดตั้ง

ใน Claude Code พิมพ์:

```
/plugin marketplace add app-adc/tracking-board
/plugin install tracking-board@tracking-board
```

## ใช้งาน

เปิด Claude Code ในโปรเจกต์ที่ต้องการ แล้วพิมพ์ เช่น:
- `ทำหน้า tracking ให้ลูกค้าดูว่าเรื่องไหนค้าง`
- `อยากได้บอร์ด Trello เล็กๆ เก็บใน Google Sheets`
- `/tracking-board`

Claude จะสร้างหน้าเว็บ + สคริปต์ `Code.gs` + คู่มือตั้งค่า แล้วบอกว่าคุณต้องทำอะไรเองบ้าง (ราว 5 นาที):
สร้าง Google Sheet → วาง `Code.gs` ใน Apps Script → Run `setupSheets` → Deploy เป็น Web app (Who has access = **Anyone**) → ใส่ URL ใน env

## บอร์ดทำอะไรได้

- คอลัมน์ตามสถานะ (ค่าเริ่มต้น: รอตอบ · รอทีมเรา · กำลังทำ · เสร็จแล้ว · พักไว้) · **ลากการ์ดย้ายสถานะ** · บันทึกการย้ายให้อัตโนมัติ
- สร้าง / แก้ / ซ่อนเรื่อง · คอมเมนต์ · กำหนดเสร็จ (เลยกำหนดขึ้นแดง) · "ค้าง N วัน" · งานที่ติดเพราะเรื่องนี้
- การ์ดตัวเลขกดกรองได้ · ตัวกรองสถานะ/ประเภท/โมดูล/รอบส่งงาน/ค้นคำ · มุมมองบอร์ด / รายการ / ตามรอบส่งงาน
- ลิงก์รายเรื่อง `?item=T-001` · ดาวน์โหลด CSV · ใช้บนมือถือได้
- ไม่มีระบบล็อกอิน — คนคอมเมนต์/สร้าง/แก้ต้องพิมพ์ชื่อเองทุกครั้ง · กันแก้ทับกัน · กันข้อความกลายเป็นสูตรในชีต

## โครงสกิล

| path | ใช้ทำอะไร |
| --- | --- |
| `skills/tracking-board/SKILL.md` | ขั้นตอน · ขั้นสัมภาษณ์ · ค่าเริ่มต้นพร้อมเหตุผล · กับดักทางเทคนิค |
| `assets/Code.gs` | สคริปต์ฝั่ง Google |
| `assets/core/` | โค้ดแกน TypeScript (ไม่ผูกเฟรมเวิร์ก — ปรับแค่ `tracking-config.ts`) |
| `references/` | สเปกหน้าจอ · คู่มือปรับแต่ง · คู่มือตั้งค่า Google · ตัวอย่าง Vue 3 |
| `scripts/test-code-gs.js` | ทดสอบ `Code.gs` กับชีตจำลอง: `node scripts/test-code-gs.js assets/Code.gs` |

## หมายเหตุ

- ใครมีลิงก์หน้าเว็บก็ใช้บอร์ดได้ และชื่อพิมพ์เอง — อย่าใส่ข้อมูลลับในบอร์ด
- เอาขึ้นเว็บจริงต้องตั้ง **SPA fallback** ของโฮสต์ ไม่งั้นวาง URL `/tracking` ตรงๆ แล้ว 404 (สกิลตั้งให้ / มีตารางในคู่มือ)
